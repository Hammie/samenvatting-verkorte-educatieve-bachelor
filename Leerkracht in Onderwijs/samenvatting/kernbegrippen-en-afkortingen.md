# Kernbegrippen en afkortingen - Leerkracht in Onderwijs

Deze lijst bundelt de kernbegrippen uit de vijf lessen. Gebruik ze vooral om casussen snel te herkennen en naar de juiste regel, actor of procedure te leiden.


## Les 1 - Deontologie, onderwijscontext en solliciteren

| Begrip | Korte betekenis |
| --- | --- |
| LinO | Afkorting voor `Leerkracht in Onderwijs`. |
| Beroepssocialisatie | Leren denken en handelen volgens de professionele verwachtingen van het beroep. |
| Macro | Niveau van beleid, onderwijsstructuur, netten, koepels en inspectie. |
| Meso | Niveau van school, schoolbestuur, scholengroep en schoolorganisatie. |
| Micro | Niveau van klas, leerling en concrete interactie tussen leraar en leerling. |
| Schoolbestuur | Inrichtende macht en werkgever van het schoolpersoneel. |
| Onderwijsnet | Indeling van onderwijs volgens inrichter en financiering, zoals officieel of vrij onderwijs. |
| Deontologie | Plichtenleer van een beroep. |
| Ambtsgeheim | Discretieplicht van leraren rond informatie die ze door hun functie kennen. |
| Beroepsgeheim | Strengere geheimhoudingsplicht voor bepaalde beroepsgroepen, zoals CLB-medewerkers. |
| Morele casus | Evaluatieopdracht waarin een moreel dilemma systematisch geanalyseerd wordt. |


## Les 2 - Je loopbaan in het onderwijs

| Begrip | Korte betekenis |
| --- | --- |
| Aanstellingsvoorwaarden | Voorwaarden waaraan je moet voldoen om in het onderwijs te kunnen starten. |
| Onderwijsbevoegdheid | Bevoegdheid om een bepaald ambt, vak, specialiteit, module of opleiding uit te oefenen. |
| BPB | Bewijs van pedagogische bekwaamheid. |
| VE | Vereist bekwaamheidsbewijs. |
| VO | Voldoende geacht bekwaamheidsbewijs. |
| AND | Ander bekwaamheidsbewijs. |
| TABD | Tijdelijke aanstelling van bepaalde duur. |
| TADD | Tijdelijke aanstelling van doorlopende duur. |
| Vaste benoeming | Benoeming met sterkere werkzekerheid, reaffectatierecht, ruimer verlofstatuut en overheidspensioen. |
| Aanvangsbegeleiding | Begeleiding van startende leraren via wegwijs-, werk- en leerbegeleiding. |
| Functiebeschrijving | Document met kerntaken waarop het evaluatieproces steunt. |
| Geldelijke anciënniteit | Anciënniteit die je loonontwikkeling bepaalt. |
| Dienstanciënniteit | Anciënniteit die onder meer voorrang bij TADD en vaste benoeming beïnvloedt. |
| Prestatiebreuk | Teller/noemer waarmee je opdrachtvolume wordt uitgedrukt. |
| Plageuur | Uur tussen minimum- en maximumopdracht zonder extra loon. |
| Reaffectatie | Toewijzing aan een andere betrekking wanneer de benoemde betrekking wegvalt. |


## Les 3 - Rechten, plichten en aansprakelijkheid

| Begrip | Korte betekenis |
| --- | --- |
| Rechtspositie | Juridisch kader dat rechten, plichten, statuut en procedures van leraren bepaalt. |
| Inrichtende macht | Schoolbestuur dat personeel aanstelt en tuchtmacht kan uitoefenen. |
| Tucht | Sanctionering van plichtsverzuim of ernstig professioneel fout gedrag. |
| Preventieve schorsing | Maatregel van orde, geen tuchtmaatregel, waarbij aanwezigheid tijdelijk niet wenselijk is. |
| Blaam | Morele tuchtstraf of waarschuwing. |
| Afzetting | Zwaarste tuchtmaatregel: definitieve verwijdering en verlies van overheidspensioen. |
| Burgerlijke aansprakelijkheid | Plicht tot herstel of vergoeding van schade aan een derde. |
| Strafrechtelijke verantwoordelijkheid | Verantwoording voor een wettelijk omschreven misdrijf. |
| Contractuele aansprakelijkheid | Aansprakelijkheid wegens fout bij uitvoering van een overeenkomst. |
| Buitencontractuele aansprakelijkheid | Aansprakelijkheid voor schade buiten contractueel verband. |
| Algemene BA | Aansprakelijkheid voor eigen fout, schade en oorzakelijk verband. |
| Specifieke BA | Aansprakelijkheid van de onderwijsinstelling voor schade door leerlingen onder toezicht. |
| Fout | Schending van wettelijke regel of zorgvuldigheidsnorm. |
| Schade | Economisch of niet-economisch nadeel aan een beschermd belang. |
| Oorzakelijk verband | Verband waarbij de schade zich zonder de fout niet zo zou hebben voorgedaan. |
| Schuldbekwaam | Bekwaam om persoonlijk aansprakelijk te zijn; in de les gekoppeld aan de grens vanaf `12` jaar. |
| Toezicht | Verantwoordelijkheid om leerlingen passend te begeleiden en risico's redelijk te voorkomen. |


## Les 4 - Interne schoolorganisatie

| Begrip | Korte betekenis |

| Schoolcultuur | Gedeelde waarden, normen, gewoonten, verhalen en verwachtingen in een schoolteam. |

| Rol | Functionele opdracht binnen de school, zonder aparte formele loopbaanstatus. |

| LOC | Lokaal onderhandelingscomité voor personeelsaangelegenheden. |
| CPBW | Comité voor preventie en bescherming op het werk. |
| Klassenraad | Orgaan bevoegd voor toelating, vorming, evaluatie en deliberatie. |
| Begeleidende klassenraad | Klassenraad die begeleiding en opvolging van leerlingen bespreekt. |
| Delibererende klassenraad | Klassenraad die eindejaarsbeslissingen neemt. |
| Interne beroepscommissie | Schoolinterne commissie voor beroep tegen evaluatiebeslissingen of definitieve uitsluiting. |
| Juridisering | Ervaring of proces waarbij onderwijs sterker door regels, procedures en juridische logica wordt bepaald. |
| Regeldichtheid | Hoeveelheid, omvang en complexiteit van regelgeving. |
| Verantwoordingsdruk | Druk om beslissingen en handelingen voortdurend te documenteren, motiveren en bewijzen. |
| Planlast | Administratieve last die als overbodig of demotiverend wordt ervaren. |
| VLOR | Vlaamse Onderwijsraad, advies- en overlegorgaan voor onderwijsbeleid. |


## Les 5 - Kwaliteitszorg, doorlichting en inspectie

| Begrip | Korte betekenis |
| --- | --- |
| Kwaliteitszorg | Systematisch onderzoeken, waarborgen, verbeteren en openbaar maken van onderwijskwaliteit. |
| Externe kwaliteitszorg | Kwaliteitsbewaking door externe deskundigen, inspectie, visitaties of subsidiegever. |
| Interne kwaliteitszorg | Kwaliteitsontwikkeling door de school zelf. |
| OK / ROK | Referentiekader voor Onderwijskwaliteit; kader voor kwaliteitsverwachtingen. |
| Kwaliteitsverwachting | Verwachting waaraan onderwijsinstellingen moeten tegemoetkomen. |
| Kwaliteitsbeeld | Verdere verduidelijking van een kwaliteitsverwachting. |
| Ontwikkelingsschaal | Schaal waarmee inspectie inschat hoe sterk een school aan een verwachting tegemoetkomt. |
| Doorlichting | Extern onderzoek door de onderwijsinspectie naar kwaliteit en regelgeving. |
| BVH | Bewoonbaarheid, veiligheid en hygiëne. |
| Onderwijsspiegel | Jaarlijkse rapportering van de onderwijsinspectie. |
| ScholenKompas | Dashboard met cijfergegevens per basis- of secundaire school. |
| PDCA | Plan, Do, Check, Act. |
| Pedagogische begeleidingsdienst | Ondersteunt scholen bij kwaliteitsvol onderwijs en professionalisering. |
