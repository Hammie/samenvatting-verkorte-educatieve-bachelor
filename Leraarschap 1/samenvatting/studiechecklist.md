# Studiechecklist LER1

Gebruik deze checklist om te controleren of je de leerstof actief kunt toepassen.

## Basis

- [ ] Ik kan uitleggen wat LER1 bedoelt met een krachtige leeromgeving.
- [ ] Ik kan kernbegrippen correct definieren en toepassen op een concrete klascontext.
- [ ] Ik kan verbanden leggen tussen minstens twee lessen per antwoord.
- [ ] Ik kan een didactische keuze verantwoorden vanuit doelen, beginsituatie, werkvorm, motivatie en feedback.

## Per les

- [ ] Les 1: ik kan kwalificatie, socialisatie en subjectivering uitleggen en verbinden met mijn onderwijsvisie.
- [ ] Les 2: ik kan warm klasklimaat, welbevinden, groeimindset, groeitaal en leraarverwachtingen toepassen.
- [ ] Les 3: ik kan het didactisch model gebruiken om een les te analyseren of te ontwerpen.
- [ ] Les 4: ik kan sterke leerdoelen formuleren en feedback koppelen aan feed up, feed back en feed forward.
- [ ] Les 5: ik kan breinprincipes, executieve functies en leerstrategieen vertalen naar concrete leskeuzes.
- [ ] Les 6: ik kan motivatie verklaren met ZDT, ABC, attributie en het Leraarkompas.
- [ ] Les 7: ik kan adolescentie gebruiken om beginsituatie, gedrag en ondersteuning beter te begrijpen.
- [ ] Les 8: ik kan LER1 samenvatten als een kader voor didactisch redeneren en lesvoorbereiding.

## Oefenen voor de kennistoets

- [ ] Ik kan bij elk kernbegrip een voorbeeld geven uit een klas- of lessituatie.
- [ ] Ik kan uitleggen waarom een aanpak werkt, niet alleen beschrijven wat de leraar doet.
- [ ] Ik kan een zwakke leskeuze verbeteren en verantwoorden met LER1-begrippen.
- [ ] Ik kan een mini-lesvoorbereiding toetsen aan doelen, beginsituatie, inhoud, werkvorm, motivatie, evaluatie en feedback.

## Laatste controle

- [ ] Ik heb de kernbegrippenlijst actief herhaald.
- [ ] Ik heb de synthesenotitie over lesvoorbereiding doorgenomen.
- [ ] Ik heb praktische exameninformatie gecontroleerd via de officiele kanalen.
