# Samenvattingen

Deze repository verzamelt onofficiele studenten-notities per vak. De inhoud is bedoeld als studiehulp voor medestudenten en vervangt geen cursusmateriaal, Toledo-communicatie of lessen van docenten.

## Vakken

- [Leraarschap 1](Leraarschap%201/README.md)
- [Leerkracht in Onderwijs](Leerkracht%20in%20Onderwijs/README.md)

## Gebruik

Elke vakmap bevat een eigen README en een map met Markdown-samenvattingen. Bestudeer de notities samen met je eigen lesmateriaal en controleer praktische exameninformatie altijd via de officiele kanalen.
